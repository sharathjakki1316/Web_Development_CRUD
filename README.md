# Student Management System

A simple and responsive **Student Management System** developed as a Web Development Minor Project.

This application implements CRUD operations using **HTML, CSS, JavaScript, and LocalStorage**.

---

## 📌 Project Overview

The Student Management System allows users to manage student records through a simple web interface.

Users can:

- Add new students
- View student records
- Edit existing student details
- Delete individual students
- Delete all students
- Search students
- Store data using LocalStorage
- Validate student input
- Switch between Light Mode and Dark Mode
- Keep the selected theme after refreshing the page

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

---

## ✨ Features

### 1. Add Student

Users can enter:

- Student Name
- Email
- Course
- Age

and add the student to the records.

### 2. View Students

All saved student records are displayed in a table containing:

- ID
- Name
- Email
- Course
- Age
- Actions

### 3. Update Student

Users can edit the details of an existing student.

### 4. Delete Student

Users can delete an individual student after confirmation.

### 5. Clear All Students

All student records can be removed at once after confirmation.

### 6. Search Students

Students can be searched using:

- Name
- Email
- Course

### 7. LocalStorage

Student data is stored in the browser's LocalStorage, allowing records to remain available after refreshing the page.

### 8. Form Validation

The application validates:

- Student name
- Email address
- Age

before saving the record.

### 9. Dark Mode

Users can switch between:

- 🌙 Dark Mode
- ☀️ Light Mode

The selected theme is saved using LocalStorage.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start adding and managing student records.

No server or database is required because the application uses browser LocalStorage.

---

## 💡 CRUD Operations

CRUD stands for:

| Operation | Description |
|---|---|
| Create | Add a new student |
| Read | View student records |
| Update | Edit student information |
| Delete | Remove student records |

## 🎯 Project Objective

The objective of this project is to develop a simple web-based Student Management System and demonstrate the implementation of CRUD operations using front-end web technologies and browser LocalStorage.
